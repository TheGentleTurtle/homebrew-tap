# Homebrew Tap

Homebrew packages maintained by TheGentleTurtle.

## nav

```sh
brew install TheGentleTurtle/tap/nav
```

## Tack

Install Tack from the tap's public, checksum-verified binary release:

```sh
brew install --cask TheGentleTurtle/tap/tack
```

Tack's source and in-app update release remain private. To use the update
button, sign in to an account with access:

```sh
gh auth login --hostname github.com
```

To ask Homebrew to reinstall or upgrade the cask instead, use
`brew reinstall --cask TheGentleTurtle/tap/tack` or
`brew upgrade --cask --greedy TheGentleTurtle/tap/tack`.
